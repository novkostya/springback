springback

Keep the apps you own, after Apple stops offering them.

Fake tool layer. Nothing here is talking to a real device, Apple ID or App Store — these are fixtures for developing on a box with no hardware.

Archive

App Store id . This will download roughly 500 MB and can take a while — the page waits for it.

This app is delisted, so nothing can look its App Store id up — it is in no store, and the device does not carry the number either. Enter it once and springback remembers it for good.

The id is the digits in the app's old App Store link: apps.apple.com/app/id123456789 — from a bookmark, an old email receipt, or a web archive of the app's page.

springback never buys anything. If the account below does not already own this app, the download fails with "license not found" — try another Apple ID.

Install

A different Apple ID on the device is fine. The licence check happens the first time the app is opened, not now: iOS will ask for the Apple ID that owns the app on first launch, and it works from then on.
